# Scripts de seguridad (NO PUBLICAR)

Estos scripts contienen, por su naturaleza, la lista de las
claves del sistema para poder comprobar que no se filtran.

Por eso viven aqui y NO se publican en el repositorio.

Contenido:
- `auditar-secretos.py` — busca claves en el repo publico
- `verificar-fugas.py` — comprueba las dos fugas de la Fase 0
- `fase0-detener-fugas.py` — saca las claves del historial
- `comprobar-supabase-rls.py` — verifica RLS en Supabase
- `configurar-acceso.py` — monta el acceso del panel
- `probar-acceso.py` — prueba contrasena y seguridad
